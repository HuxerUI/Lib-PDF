# v0.2.0

- 新增多平台发布矩阵：Windows x64、Linux x86_64/aarch64、macOS arm64/x86_64、Android arm64-v8a/x86_64、iOS Simulator。
- 版本信息统一由仓库根 `VERSION` 提供，并写入每个包：Windows 可执行文件的 FileVersion/ProductVersion、macOS `CFBundleShortVersionString`、Android `versionName`/`versionCode`、iOS `CFBundleShortVersionString`/`CFBundleVersion`，以及发行包内的 `VERSION` 文件。
- 发行包文件名带版本与平台架构，例如 `pdf-preview-0.2.0-linux-aarch64.tar.gz`；release 说明从 `docs/releases/<tag>.md` 读取。
- 示例在标题栏与状态栏显示运行版本与平台（如 `v0.2.0 · Windows`），移动端启动自检结果同样带版本，CI 会校验运行时版本与 `VERSION` 一致。
- 库新增 `huxerui::pdf::Version()`，返回值与打包版本同源。
- Android 按 ABI 分别产出 APK，`versionCode` 由语义版本推导（`major*10000 + minor*100 + patch`）。
- 修复 Windows 发行包捆绑的 MSVC 运行库版本，改为匹配构建工具集的 redist 目录。

## English

- Add a multi-platform release matrix: Windows x64, Linux x86_64/aarch64, macOS arm64/x86_64, Android arm64-v8a/x86_64, and the iOS Simulator.
- The repository `VERSION` file is now the single version source and is embedded in every package: Windows `FileVersion`/`ProductVersion`, macOS `CFBundleShortVersionString`, Android `versionName`/`versionCode`, iOS `CFBundleShortVersionString`/`CFBundleVersion`, and a staged `VERSION` file.
- Release archives carry the version and platform, for example `pdf-preview-0.2.0-linux-aarch64.tar.gz`; release notes are read from `docs/releases/<tag>.md`.
- The example shows its runtime version and platform in the title and status bar (`v0.2.0 · Windows`), and the mobile launch self-check reports the same version, which CI compares against `VERSION`.
- Add `huxerui::pdf::Version()`, returning the same value the packages are built from.
- Produce one Android APK per ABI, with `versionCode` derived from the semantic version (`major*10000 + minor*100 + patch`).
- Fix the bundled MSVC runtime in the Windows package to use the redist matching the build toolset.
