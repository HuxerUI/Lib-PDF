# PDF Preview

Desktop demo for Lib-PDF, following the structure used by the other HuxerUI libraries:

```text
examples/preview/
  CMakeLists.txt
  HuxerUIProject.cmake
  src/app.cpp
  resources/raw/guide.pdf
  resources/strings/default.properties
  platform/windows/
  platform/macos/
  platform/linux/
```

The demo opens a bundled three-page field guide at startup. Use **Open PDF** to
choose a local document, or **Load sample** to return to the guide. Password PDFs
show a secure password field and **Unlock** button. Controls include page
navigation, 25–300% zoom (click the percentage to reset), clockwise rotation,
annotation visibility, and light/dark themes.

The **Document** panel displays metadata and searches the current page. An active
query is repeated when changing pages. The **Page text** panel supports native
selection and copying, with a 12,000-byte display limit. Search reports match
counts; it does not draw highlights. File opening, parsing, rendering, text
extraction, and search use asynchronous tasks/workers to keep the UI responsive.
The sample includes a landscape page and a yellow annotation that can be toggled.

## Standalone build

From the repository root:

```sh
cmake -S examples/preview -B build-demo -DHUXERUI_HOME=/path/to/HuxerUI
cmake --build build-demo --config Release --target example_pdf --parallel
```

On Windows, run `build-demo/Release/example_pdf.exe`. On other desktops, locate
`example_pdf` or the **PDF Preview** app bundle in `build-demo`. The Windows
PDFium DLL and the compiled application resource package are staged by CMake.
Keep the resource package with the executable when copying the built demo.

Offline builds can also pass
`-DHUXERUI_PDF_FETCH_PDFIUM=OFF -DHUXERUI_PDF_PDFIUM_ROOT=/path/to/pdfium`.
The default macOS SDK requires macOS 13 or later.

Alternatively, enable `HUXERUI_PDF_BUILD_EXAMPLES=ON` in the root library build;
the same `example_pdf` target is then built under `build/examples/preview`.

`HuxerUIProject.cmake` exposes app plan metadata for HuxerUI tooling, and compiler-free
library-graph discovery is supported. This demo currently has Windows, macOS, and
Linux entry points. Mobile and Web preview projects are not supplied.

The PDF resource is generated by `python scripts/generate_demo.py` from the root;
Python is not required to build or run the demo. The resource has no runtime
dependency on the source tree or the test fixtures.

When building from the root with `HUXERUI_PDF_BUILD_TESTS=ON`,
`HUXERUI_PDF_BUILD_EXAMPLES=ON`, and `HUXERUI_BUILD_TESTING_LIBRARY=ON`, CTest also
runs `pdf.demo` against this application and its actual packaged resources. It
covers initial loading, search, page changes, zoom, rotation, annotation toggles,
text inspection, theme switching, and reloading the sample without opening windows.
